# WaveRoot debugging interface (Track C, ticket C05)

React + TypeScript (Vite) viewer for WaveRoot reports. It opens saved
documents only; opening a report never launches a simulation.

```sh
npm --prefix ui ci
npm --prefix ui run dev        # local development server
npm --prefix ui run build      # typecheck + production build (ui/dist)
npm --prefix ui test           # behavior tests (Vitest + Testing Library)
python3 ui/scripts/visual_check.py /tmp/out   # Chrome screenshots, layout + latency checks (after build)
uv run python ui/scripts/make_fixtures.py     # regenerate ui/fixtures (runs the real CLI)
```

## What it reads

Every document is validated against schema 1 before anything renders
(`src/model/validate.ts`, mirroring `src/contracts.py`): unknown or missing
fields, width/bit mismatches, dangling graph references, bad ranks, and
unknown schema versions are rejected with an explanation.

- **Run records** from `python -m src.app.cli analyze … --json` (or the saved
  `report.json`), wrapping `ComparisonResult` and an optional `CausalReport`.
- **Mock fixtures** such as `tests/fixtures/mock_fifo_failure.json`.
- **Bare `CausalReport` JSON.**

## Guarantees

- Timestamps stay BigInt end to end; only bounded window offsets become pixels.
  A one-tick change above 2^53 stays distinguishable.
- Bit strings stay strings. Hex shows `x`/`X`/`z`/`Z` per nibble; decimal views
  are refused for unknown bits. Raw bits are always shown.
- One shared selection state (`src/state/selection.ts`) implements ui-spec rules
  1–5. The first-failure anchor is report data and cannot be moved.
- Source text is shown as the analyzed code only when its SHA-256, computed in
  the browser, matches the report. A same-named file with other bytes is shown
  as a revision mismatch. Supply files with "Add source files…".
- Synthetic data carries a persistent "Sample data" badge with its fixture id.
  Real run records compared by the Track C self-check say so.
- Assertion text is displayed and copied, never executed; nothing is called
  validated without a tool named in the report.

## Fixtures (`ui/fixtures/`)

Generated by `scripts/make_fixtures.py` through the Python contracts.
`real_*.json` are genuine CLI run records (Verilator/Icarus); only machine-local
paths were rewritten to be repository-relative. The others are synthetic UI
states derived from the mock fixture; the three invalid ones are confirmed to
be rejected by `src/contracts.py` as well (`tests/track_c/test_ui_fixtures.py`).

## Not yet

- No live API: the offline/API-error state belongs to C06.
- Causal graphs come only from fixtures until Track B lands; waveform windows
  arrive with Track A's provider. Real run records today show the observed
  failure as unlocalized, with the reason.
