# WaveRoot debugging interface (Track C, ticket C05)

React + TypeScript (Vite) viewer for WaveRoot reports. It opens saved
documents only; opening a report never launches a simulation.

```sh
npm --prefix ui ci
npm --prefix ui run dev        # local development server
npm --prefix ui run build      # typecheck + production build (ui/dist)
npm --prefix ui test           # behavior tests (Vitest + Testing Library)
python3 ui/scripts/visual_check.py /tmp/out   # Chrome screenshots, layout + latency checks (after build)
uv run python ui/scripts/make_fixtures.py     # regenerate ui/fixtures (runs the real CLI)
```

## What it reads

Every document is validated against schema 1 before anything renders
(`src/model/validate.ts`, mirroring `src/contracts.py`): unknown or missing
fields, width/bit mismatches, dangling graph references, bad ranks, and
unknown schema versions are rejected with an explanation.

- **Run records** from `python -m src.app.cli analyze … --json` (or the saved
  `report.json`), wrapping `ComparisonResult` and an optional `CausalReport`.
- **Mock fixtures** such as `tests/fixtures/mock_fifo_failure.json`.
- **Bare `CausalReport` JSON.**

## Guarantees

- Timestamps stay BigInt end to end; only bounded window offsets become pixels.
  A one-tick change above 2^53 stays distinguishable.
- Bit strings stay strings. Hex shows `x`/`X`/`z`/`Z` per nibble; decimal views
  are refused for unknown bits. Raw bits are always shown.
- One shared selection state (`src/state/selection.ts`) implements ui-spec rules
  1–5. The first-failure anchor is report data and cannot be moved.
- Source text is shown as the analyzed code only when its SHA-256, computed in
  the browser, matches the report. A same-named file with other bytes is shown
  as a revision mismatch. Supply files with "Add source files…".
- Synthetic data carries a persistent "Sample data" badge with its fixture id.
  Real run records compared by the Track C self-check say so.
- Assertion text is displayed and copied, never executed; nothing is called
  validated without a tool named in the report.

## Fixtures (`ui/fixtures/`)

Generated by `scripts/make_fixtures.py` through the Python contracts.
`real_*.json` are genuine CLI run records (Verilator/Icarus); only machine-local
paths were rewritten to be repository-relative. The others are synthetic UI
states derived from the mock fixture; the three invalid ones are confirmed to
be rejected by `src/contracts.py` as well (`tests/track_c/test_ui_fixtures.py`).

The real FIFO and ALU failures carry Track B's causal report (regenerated
after #27); `real_alu_x_unlocalized.json` is the same ALU run with
`--causal none`, kept for the unlocalized state. The RTL behind them is bundled
(`src/samples.ts`) and matched to each report by SHA-256, never by name.

## Public read-only viewer (Vercel)

`VITE_WAVEROOT_HOSTED=1 npm run build` builds a viewer that never contacts an
analysis service: the run panel is replaced by a note that points to the
README, and visitors open the bundled real reports or their own
`report.json`. Analyses need Verilator/Icarus, so they only run locally
(`uv run waveroot serve`).

`ui/vercel.json` holds the build settings and response headers (a
Content-Security-Policy with `connect-src 'none'`, no framing, no referrer). To
deploy, import the repository in Vercel and set **Root Directory** to `ui`; keep
"Include files outside the Root Directory" on, because the bundled samples read
`tests/fixtures/` and `benchmarks/`. Check a build locally with the headers
applied by serving `ui/dist` with them and opening it in a browser.

### Dark dashboard (React 19)

The workbench uses Tailwind CSS, React Flow for pan/zoom causal graphs, and
high-DPI Canvas waveform tracks with a separate selection/failure cursor overlay.
Clicking graph nodes, ranked suspects, or waveform tracks shares one selection;
source text is SHA-256 checked and syntax highlighted. Binary bits remain visible
beside the selected numeric radix; the failure hero shows hex alongside binary
by default. Assertions copy their validation status with the SystemVerilog text.

Schema 1 is unchanged. Confidence is explicitly “not supplied” because suspect
ranks are ordinal, not probabilities. The fixture has no assertions. Sequential
edges mean `before → settled` at one clock edge and are dashed amber; a genuine
previous-cycle carry is labeled `−1 cycle`, in solid cyan. Unknown-control paths
are labeled and purple; pruned paths are dimmed when revealed.

“10 cycles” derives ten complete intervals from eleven recorded rising edges.
A short trace, missing clock, dump gap, or cursor outside those complete intervals
falls back to the available window instead of inventing time or hiding selection.
Absolute timestamps remain BigInt; before-phase readouts use strictly earlier
samples while the cursor stays on the exact observation timestamp.

For browser checks: `python3 -m playwright install chromium`, build, then
`python3 ui/scripts/visual_check.py work/visual`. Set `WAVEROOT_BROWSER_CHANNEL=chrome`
to use an installed Chrome instead. The script checks responsive layouts and real
graph-to-waveform/source selection, and records large-report interaction timings.
